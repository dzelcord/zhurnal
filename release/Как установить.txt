ЖУРНАЛ ВОСКРЕСНОЙ ШКОЛЫ ДЛЯ MAC

1. Какой файл скачать
   Откройте меню Apple (яблоко в левом верхнем углу) и выберите «Об этом Mac».
   Если там написано «Чип Apple M1» (M2, M3, M4 и далее), нужен файл Zhurnal-Mac-arm64.zip.
   Если написано «Процессор Intel», нужен файл Zhurnal-Mac-x64.zip.

2. Установка
   Проверьте размер скачанного файла: щёлкните по нему правой кнопкой, «Свойства».
   Для arm64 должно быть 98 059 070 байт, для x64 102 634 378 байт. Если меньше,
   файл скачался не полностью: удалите его и скачайте снова.
   Дважды щёлкните по zip-файлу. Появится программа «Журнал воскресной школы»
   (внутри она называется Zhurnal.app). Перетащите её в папку «Программы» (Applications).

3. Первый запуск (делается один раз)
   Программа не подписана сертификатом Apple, поэтому при первом запуске Mac её не пустит.
   Откройте программу «Терминал» (через поиск Spotlight: Cmd + Пробел, слово «Терминал»),
   вставьте строку ниже и нажмите Return:

   xattr -cr /Applications/Zhurnal.app && codesign --force --deep --sign - /Applications/Zhurnal.app

   После этого программа открывается обычным двойным щелчком.

4. Где хранятся записи
   Все записи хранятся только на этом Mac. В меню программы «Данные» есть пункт
   «Показать папку с журналом и копиями». Там лежит файл journal.json и папка
   «Резервные копии» с копией журнала за каждый день работы (последние 60 копий).
   Веб-версия журнала в Claude и эта программа хранят записи отдельно и не обмениваются ими.

5. Полезные сочетания клавиш
   Cmd + [  предыдущая группа
   Cmd + ]  следующая группа
   Cmd + плюс / Cmd + минус  крупнее / мельче
